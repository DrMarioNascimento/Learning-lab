[https://drmarionascimento.github.io/Learning-lab/](https://drmarionascimento.github.io/Learning-lab/)

## Sobre o projeto

O **Laboratório do Pesquisador** permite que o aluno:

- Escolha uma subárea da Educação Física
- Receba um cenário de pesquisa sorteado
- Construa o delineamento metodológico passo a passo
- Receba um parecer automático sobre o rigor científico do projeto

O sistema possui dois modos:
- **Modo Clássico** — com orientação e feedback estruturado
- **Modo Livre** — para exploração

Também inclui um **Acervo Teórico**.

## Tecnologias utilizadas

- HTML5 + CSS3 + JavaScript (vanilla)
- Design mobile-first (otimizado para smartphones)
- Dados estruturados em JSON
- Interface limpa e focada na experiência do estudante
